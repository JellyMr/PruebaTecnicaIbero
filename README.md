# Prueba tecnica de catálogo de productos 
Consta de consulta de producto activos, inserción de nuevos productos y baja lógica

Mi idea para la realización de esta prueba fue una versión limpia y bien estructurada de la prueba con los requerimientos establecidos para que sea simple pero funcional.

En el archivo **QUERYS.sql** se encuentra el código necesario para crear la base de datos y las tablas necesarias para el funcionamiento de la aplicación, lo único que se debería de cambiar es la variable de conexión en appsettings.json
